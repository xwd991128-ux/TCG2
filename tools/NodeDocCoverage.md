# 规则图节点覆盖清单（NodeDoc 全量 × 运行时实现）— 判据 v3

判据：剥离行注释 → 剔除 `IsSupportedAction` 白名单 → 按 `case "id":`（动作分派）/ `*.action == "id"`（**取值通道**）两种信号判定，两者**都算已实现**。

统计：共 **301** 个节点｜**已实现 301**（动作 case 267 + 取值通道 34）｜**未实现 0**。

> v1 判据要求 `case` 后紧跟 `{`，漏掉了内联单语句 case 与条件式分派；v2 修正后仍把"取值通道实现"单列成"待确认"。
> v3 依据：2026-09 对 16 个"仅条件式"节点**逐个核实**（读实现所在方法）→ 14 个真实现 + 2 个部分实现（111031 端口被编辑器移除、113001 `elements` 初始元素被忽略），**没有一个是残留引用**。
> 指标口径：对局报告的 `nodoc_logs` 统计 `[NodeDoc]` 前缀日志，已被 GameLog 开关接管（`gamelog_verbose=False` 时恒为 0），不能用于判断图是否执行。
