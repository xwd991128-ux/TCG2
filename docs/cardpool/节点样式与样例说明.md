# 节点样式与样例说明

> 对应沙盒文件：`docs/节点编辑器-开发规格.md`。这里给出节点**样式文本介绍** + 一张**工作样例卡**（`样例-抽2张不同种族随从.diycard`）的连线解读，供 AI / 开发理解节点体系并复现。

---

## 一、节点样式文本介绍（UI 长什么样）

一个节点 = **头部一行 + 若干"配对端口行" + 底部说明区**。

### 1. 头部 Header（高 32px）
- 最左 **6px 分类色条**，贯穿整卡，标识节点分类。
- 标题文字（字号 14，左 padding 12）。
- 右上角两个按钮：**收起「一」**（节点缩成一行，线不删）、**删除「×」**（节点+线上所有连线一起删，需可撤销）。
- 下方 1px 分割线。

### 2. 端口行（核心，每行 28px / 触屏 32px）
- **输入口贴左缘、输出口贴右缘，共用同一水平中线** → 连线天然水平。
- 行数 = `max(输入个数, 输出个数)`。
- 端点锚点公式：`y = headerBottom + row*28 + 14`；`输入口圆心=(nodeLeft+6, y)`、`输出口圆心=(nodeRight-6, y)`。

### 3. 底部说明区（可折叠）
- 一句人话说明（如"对目标造成 X 点伤害"），≤2 行；无说明则高度 0。

### 4. 端口彩点配色（决定能否相连，防呆）
| 彩点 | 类型 | 线型 |
|---|---|---|
| 紫 `#7c5cff` | 执行（动作线） | 实线+箭头 |
| 蓝 `#5b9dff` | 整数 | 虚线 |
| 红 `#e5484d` | 卡牌 | 虚线 |
| 灰 `#8a8fa3` | 布尔/玩家 | 虚线 |
| 绿 `#35c28a` | 文本 | 虚线 |

**规则**：Exec 端口只能连 Exec；数据端口只能连同类型。开始拖某输出口时，仅匹配输入口变亮，其余变灰。

### 5. 数值输入取值（X 在哪配）
每个数据输入口两种来源，覆盖关系：
1. **手填固定值**（默认）：节点显示可点数值框（如 `X = 5`），点它进右侧参数面板改。
2. **接取值线**：连上游节点后变为 `← 目标攻击力`，运行时用上游值。
- 判断：`来源连线 != null ? 用上游 : 用本口默认值`（线拔掉即回落默认值，端口不空）。

## 二、样例卡：打出时：抽 2 张不同种族的随从牌

实体文件：`样例-抽2张不同种族随从.diycard`（可被 `CardGraphData.FromJson` 解析）。

### 设计思路（两步走，全用现成节点）
**第一步：先取 2 个不同种族**
- 取牌库随从集合 → 取所有元素的"种族"属性 → 集合去重 → 随机取 2 个。
- 关键：去重在"随机取 2"之前，因此取到的 2 个种族**必然不同**。

**第二步：对每个种族各抽 1 张**
- 遍历这 2 个种族 → 在当前种族里随机取 1 张随从 → 抽入目标（手牌）。

### 节点清单（id / defineId / 作用）
| id | defineId | 作用 | 输出 |
|---|---|---|---|
| trg | `Trig_OnPlay` | 打出时触发 | 执行 |
| lib | `101008` | 获取牌库随从集合 | 集合 |
| races | `111031` | 取所有元素的种族属性 | 集合(种族) |
| racdedup | `111010` | 集合去重（种族不重复） | 集合 |
| pick2 | `111028` | 随机取 X 个（X=2） | 集合(2个种族) |
| loop | `211001` | 遍历这 2 个种族，逐个执行 | 每元素=种族 |
| filter | `111012` | 筛选种族 = 当前元素 | 集合(该族随从) |
| rand1 | `111008` | 该族随机取 1 张 | 卡牌 |
| draw | `201003` | 抽目标卡牌（进手牌） | 执行 |

> defineId 为示例映射，开发按 `阶段2-节点系统全集清单.md` 对齐实际数值。

### 连线解读（动作线 = 顺序，数据线 = 传值）
- **动作线（Exec，实线）** 决定执行顺序：
  `trg → lib → loop → draw`
  （`loop → draw` 表示遍历每轮都执行一次抽牌。）
- **数据线（虚线）** 决定传值：
  - `lib.集合 → races.集合`
  - `races.集合 → racdedup.集合`
  - `racdedup.集合 → pick2.集合`，`2 → pick2.X`
  - `pick2.集合 → loop.元素集合`，`lib.集合 → filter.集合`
  - `loop.当前元素(种族) → filter.筛选值`，`filter.集合 → rand1.集合`，`rand1.卡牌 → draw.目标`

### 一句话总结
该样例验证了：**集合运算族（去重/随机取）能拼出"抽 X 张不同 Y"的真实需求**，全部用现成节点，无需新增节点；也验证了"两线制（动作线订顺序 + 取值线传值）"足以表达这类效果。
