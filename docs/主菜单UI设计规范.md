# 主菜单全端 UI 设计规范（晨星主题）

> 主题代名：**晨星**（Amber Dawn）
> 覆盖范围：主菜单全端（登录、主菜单、卡池、牌组、对局入口、匹配、排行、开包、好友、设置等所有主菜单端 Panel）。
> 交付物：统一的设计语言（色板 / 字体 / 组件 / 间距 / 图标） + 关键界面线框。
> 风格方向：重新统一主题，从零建立一套可复用的设计 token。

---

## 1. 设计原则

1. **深底衬卡**：界面底色统一为深色，卡牌/插画作为视觉焦点浮在深底上。
2. **一金一青**：主交互色只用"晨星金"（CTA/选中/高亮），辅助信息色用"秘银青"（链接/次级）。其他颜色仅用于语义与稀有度，不用于普通装饰。
3. **三层纵深**：背景 → 面板 → 浮层，用固定的表面层级（surface 级别）区分，不用花哨阴影堆叠。
4. **可访问性**：正文对比度 ≥ 4.5:1，任何可点击控件最小可点区域 44×44。
5. **组件复用**：全端共用同一套组件预制体与 token，禁止逐界面手写样式。

## 3. 字体

- **中文字体**：思源黑体（Noto Sans CJK SC）Bold / Medium / Regular。
- **数字**：Tabular 数字（等宽数字），用于金币、回合等计数对齐。
- 字号层级（以 C# 字号）：

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 40/48 | Bold | 页面大标题 / 结算数字 |
| H1 | 30/38 | Bold | 界面主标题 |
| H2 | 24/32 | Medium | Panel 标题 |
| H3 | 18/26 | Medium | 区块小标题 |
| Body | 16/24 | Regular | 正文 |
| Body-S | 14/20 | Regular | 次级正文 / 按钮 |
| Caption | 12/18 | Regular | 辅助说明、时间戳 |

---

## 4. 间距与圆角

- **间距基准 4px**，常用步进：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 面板内边距：大面板 24，卡片 16，行内元素 8。
- 卡片之间间距 12~16。

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 输入框、小按钮 |
| `--radius-md` | 10px | 常规按钮、列表项 |
| `--radius-lg` | 16px | 卡片、面板 |
| `--radius-full` | 999px | 头像、Tag、圆形图标 |

## 5. 通用组件规范

### 5.1 按钮

| 变体 | 填充 | 文字 | 描边 | 用途 |
|---|---|---|---|---|
| Primary（金） | 晨星金 | 深色文字#12141A | 无 | 主 CTA：开始对战/保存/确认 |
| Secondary | surface-3 | text-primary | border | 常规操作 |
| Ghost | 透明 | text-secondary | 无 | 弱操作：取消/关闭 |
| Danger | danger | 白 | 无 | 删除/危险操作 |

- 尺寸：大 52h / 中 44h / 小 36h；圆角 md；最小点击区域 44×44。
- 状态：default / hover（提亮）/ pressed（压暗） / disabled（降饱和灰）。

### 5.2 卡片（卡池 / 牌组）

- 背景 surface-2，圆角 lg，描边 border 1px。
- 选中态：描边变晨星金 + 顶部高亮条。
- Hover：抬升 surface-3。
- 卡面比例保持 260:360（卡池网格），缩小等比缩放。

### 5.3 导航（底部/侧边入口）

- 图标 + 文字，选中的入口用晨星金高亮 + 左侧/上侧指示条。
- 图标统一 24×24 线性风格，二态（灰/金）。

### 5.4 面板与弹窗（UIPanel）

- 弹窗：背景 surface-3，圆角 lg，居中，带半透明遮罩 `rgba(0,0,0,0.6)`。
- 标题 H2 + 右上角关闭 X（Ghost 按钮，44×44）。
- 底部操作区：主按钮靠右，取消靠左。

### 5.5 输入框

- 背景 surface-1，描边 border，聚焦时描边晨星金。
- 占位符 text-muted；错误态描边 danger。

### 5.6 列表项（好友 / 排行 / 牌组）

- 高 64，圆角 md，图标/头像 + 主文字 + 右侧操作区。
- 分隔用 1px border，不用背景色块堆叠。

### 5.7 Tag / 状态徽章

- 半径 full，内边距 8×4，文字 12px。
- 语义颜色只在需要表达状态时使用。

### 5.8 Toast / 提示

- 底部居中浮层，surface-3 白字，显示 2s 自动消失。
- 成功/错误分别用 success / danger 左侧图标。

## 7. 落地约定

1. **Token 落地**：建议用 ScriptableObject 存一套 `UIThemeData`，色/字体/间距统一取用，或导出为 `:root` CSS（Web/图集）与 UGUI 资产并联用。
2. **组件预制体**：Button / Card / Input / Panel / Toast / ListItem 各建一个通用预制体，全端复用。
3. **命名**：场景名、Panel 名、预制体名保持现状（如 `CollectionPanel`），只重构样式不改类名，减少耦合破坏。
4. **交接 AI**：以本文档色板 + 组件规范为准，逐界面替换样式，不改变现有布局结构与脚本逻辑。
