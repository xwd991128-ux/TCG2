# 服务器部署清单（云平台搭建）

> 定位：给老板/开发团队的**云平台落地装配说明**。
> 依据：回合制卡牌对战 + 账号存盘 + UGC 分发，目标同时在线约 20 人、不用域名，希望少折腾运维。

---

## 0. 结论一句话

> **一台 4核8G 轻量云主机全包**（后端服务 + MySQL + Nginx），不单独买云数据库/OSS。
> 用 Docker Compose 一键起，面板式操作，最省事。

---

## 1. 装配清单

| 项目 | 选择 | 说明 |
|---|---|---|
| 厂商 | 腾讯云 或 阿里云 **轻量应用服务器** | 图形化控制台 + 一键装环境，适合少折腾 |
| 规格 | 4核 8G / 80G SSD / 5M 带宽 | 20 人回合制绰绰有余 |
| 系统 | Ubuntu 22.04 LTS（面板镜像亦可） | 稳定、社区资料多 |
| 数据库 | 主机内 MySQL 8（Docker） | 20 人先省云库钱，量大再迁 |
| UGC 存储 | 主机本地磁盘 | .diycard + 图 + 音频；不够再上 OSS |
| 部署方式 | Docker Compose | 后端 + MySQL + Nginx 全容器化，可迁移 |

> 不用域名：直接用 **公网 IP + 端口** 访问；正式版再加域名（此时大陆机器才需要 ICP 备案）。

### 月成本（参考）
- 国内轻量 4核8G：≈ **¥80-140/月**（首年优惠更低）
- 海外轻量同档：≈ **$20-30/月**

## 2. 部署步骤

### 2.1 第一步：购买并登录主机
1. 在云厂商控制台创建一台 4核8G 轻量服务器（国内容量/区域选离玩家近的）
2. 系统镜像选 **Ubuntu 22.04**（或厂商自带面板）
3. 记录对外 **公网 IP**、root 密码/密钥
4. 用 SSH 工具（或厂商网页终端）登录主机

### 2.2 第二步：安装 Docker + Compose
```bash
# 更新软件源
sudo apt update && sudo apt -y upgrade

# 安装 Docker
curl -fsSL https://get.docker.com | sudo sh

# 安装 Docker Compose 插件
sudo apt install -y docker-compose-plugin

# 验证
docker --version
docker compose version
```

### 2.3 第三步：建部署目录与编排文件
> 建议把你最终要跑的"后端服务"镜像化后，用如下 Nginx 反向代理 + MySQL 的 compose 起步。

```yaml
# docker-compose.yml（起步骨架）
version: "3.8"
services:
  mysql:
    image: mysql:8
    container_name: tcg-mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: <设一个强密码>
      MYSQL_DATABASE: tcg
    volumes:
      - ./mysql_data:/var/lib/mysql

  backend:
    image: <你的-后端镜像>        # 回合制房间服务 + 账号鉴权 + UGC API
    container_name: tcg-backend
    restart: always
    depends_on:
      - mysql
    environment:
      DB_HOST: mysql
      DB_NAME: tcg
      JWT_SECRET: <一个随机长串>   # 账号令牌签名
    ports:
      - "8080:8080"               # WebSocket 房间端口

  nginx:
    image: nginx:alpine
    container_name: tcg-nginx
    restart: always
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./ugc:/usr/share/nginx/ugc     # UGC 静态文件
    depends_on:
      - backend
```

### 2.4 第四步：起服务
```bash
sudo docker compose up -d
sudo docker compose ps        # 查看各容器状态
```

### 2.5 第五步：放行端口 / 验证
- 在厂商安全组/防火墙放行 **80（HTTP）、8080（WebSocket）**
- 浏览器访问 `http://<公网IP>` 应能看到后端/Nginx 响应
- WebSocket 客户端连 `ws://<公网IP>:8080`

---

## 3. 需要你后端提供的服务对象（协议建议）

| 服务 | 协议 | 端口 | 说明 |
|---|---|---|---|
| HTTP API | HTTPS/HTTP | 80 | 登录/注册、账号、卡组、UGC 列表/上传 |
| WebSocket | ws | 8080 | 房间 + 对战状态同步 |
| UGC 静态 | HTTP | 80（Nginx） | 卡牌图/音频/.diycard 下载 |

### 三点核心工程提醒
1. **服务端权威**：后端跑一份游戏逻辑（复用已统一的 `GameLogic`），客户端只做表现层 → 防外挂 + 保证多端同步
2. **账号 JWT**：登录用 JWT 签发 token，后面请求带 token 鉴权，明文密码绝不下发
3. **UGC 校验**：上传前做基础校验（格式、大小、命名白名单），先本地落盘，量大再迁 OSS
